# ACG-TEL 🧬

Collaborative workflow telephone-chain system with a 7-stage color-coded cycle.

## Stages

- 🟥 **Question** — Identify the problem
- 🟧 **Brainstorm** — Generate ideas
- 🟨 **Analyze** — Deep analysis (⚙️ effort + ⏱️ time + 📐 score)
- 🟩 **Solve** — Define the solution
- 🟦 **Build** — Implement
- 🟪 **Measure** — Evaluate results
- ⬜ **Review** — Complete or cycle back to 🟥

## Features

- **Chain collaboration** — Users linked in notification chains (👥↔👥)
- **Drag-and-drop board** — Move cards through stages
- **Chat** — Discuss and create cards with `/card Title`
- **Metrics** — Track effort, time estimates, and scores per card (🧬)
- **Tags** — Color-code cards across multiple stages
- **Free** — 💰 $0
